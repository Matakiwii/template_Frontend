# Template Frontend

Template HTML puro para proyectos frontend. Este repositorio contiene una estructura base sin CSS ni JavaScript, ideal para usar como punto de partida en proyectos de desarrollo web.

## Archivos Incluidos

- **index.html** - Página principal del proyecto
- **about.html** - Página de información
- **contact.html** - Página con formulario de contacto

## Estructura HTML

Cada archivo incluye:
- Declaración DOCTYPE correcta
- Meta tags esenciales (charset, viewport)
- Estructura semántica (header, main, footer, nav, section, article)
- Elementos de formulario accesibles
- Navegación consistente entre páginas

## Características

✓ HTML puro sin dependencias
✓ Estructura semántica correcta
✓ Responsivo con meta viewport
✓ Accessible (labels en formularios, estructura correcta)
✓ Múltiples páginas ejemplo
✓ Formulario básico funcional

## Cómo Usar

1. Clona este repositorio
2. Abre cualquier archivo `.html` en tu navegador
3. Personaliza con tu propio contenido y agrega CSS/JS según necesites

## Próximos Pasos

Puedes extender este template:
- Agregando un archivo `styles.css` para estilos
- Creando un archivo `script.js` para interactividad
- Añadiendo más páginas según tu proyecto
- Implementando validación de formularios
